浏览器把上一次点过的「拒绝」记在了浏览器内部—— 即使系统设置已授权、即使刷新页面，这条记录也不会自动清除。 需要在浏览器里把本网站的摄像头改回「允许」，三条路径任选其一：

路径 A · 最快：点浏览器地址栏左侧 🔒 → 权限 → 摄像头 → 改为「允许」→ 回到本页点下方「重试相机」

路径 B · 小米/多数安卓浏览器：底部菜单 ≡ → 设置 → 隐私和安全 → 网站设置（或叫"网页设置"）→ 摄像头 → 找到本站点 → 允许

路径 C · 兜底（会清空本站数据，先导出再清）：浏览器设置 → 清除浏览数据 → 勾选「网站设置」→ 清除后重新打开本页，弹权限时点「允许」

诊断与帮助 v2.9

识别引擎是什么？v2.8 采用双通道分割引擎：白色纸张沿用「白色区域分割」（按阈值选亮区 → 填充字迹孔洞 → 最大白色连通块 → 凸包拟合四边形，角点吸附纸角）；遇到彩色封面、红头文件、深色封套等非白色物品，自动切换「种子生长分割」——以画面中央（或点选处）为种子，按自适应颜色容差生长出物品区域，遇强边缘即止，白色桌面与衬纸不会被误认，反光也无法劫持识别框。两种结果与 Canny 边缘法竞争取优，纸张出框、占满画面也能识别。

彩色纸张框不准怎么办？直接点按画面中要拍的纸张，识别会立刻以点选位置为准重新框选；再点其他位置可随时切换。仍不行就稍微拉远手机让纸边露出桌面，或拖动四个角点手动微调。

框选精度是多少？固定为高精度自动识别：框紧贴纸边、容差低，追求准确框选。若个别纸张边缘被裁掉，可稍拉远手机让纸边露出来，或拖动角点手动微调。

识别不到怎么办？稍微拉远手机，让纸张四周露出一点桌面背景，识别会大幅变准；也可点按纸张位置指定识别，或拖动四个角点手动框选。

拍错一张怎么办？右下角缩略图点红色 × 即撤销重拍；无视它继续按快门就是下一张。

彩色 / 扫描？「彩色」只裁剪保原色；「扫描」=裁剪+去阴影白底。切换在图片下方工具条。

文件包怎么用？右上角 📁：拍完一份 → 新建一份自动切换；导出只导出当前文档。

系统授权了还是打不开相机？浏览器把「拒绝」记在浏览器内部，需在浏览器内改回允许：地址栏 🔒 → 权限 → 摄像头 → 允许。

电脑上怎么用？在电脑浏览器打开本页即自动切换电脑模式：拍照用电脑摄像头；「相册」可选文件夹 / ZIP 压缩包 / 多选图片批量导入，文件夹与 ZIP 名称自动作为文档名，可选保留原图片名。

微信里怎么分享？导出选「图片直享」逐页长按图片保存/转发（多页可左右翻页）；要发 PDF/ZIP，先复制链接到系统浏览器打开再导出。

怎么发给微信？少量页选「图片直享」→ 分享 → 选微信，点开即看；多页或正式提交选 ZIP/PDF → 分享 → 选微信；没有面板就先下载，再在微信里「＋ → 文件」发送。
